# Deadliner
Дедлайнер - сайт для показа выполнения задач.

Проблема: Студенты забывают о сроках сдачи работ, контрольных и проектов, потому что задания и даты хранятся в разных чатах и записях.
Цель: Простой веб-планировщик: добавление задания, указание предмета и срока, просмотр списка и фильтрация по статусу
Основные функции первой версии: Добавлять задания и отслеживать их выполнение
